# Agentic process — bounded qualification for 0.19.0

This historical record separates implementation, offline validation, one native
application case and release publication. It is not a general native-support or
performance verdict. Evidence remains in the operator-owned external archive;
raw logs, identities, credentials and private paths are not published here.

## Implementation and offline checks

The internal structured model and owned composition are opt-in. The required
runtime gate covers model/reducer/service, real temporary SQLite and canonical
PostgreSQL adapter transport fixtures, assignment, CAS, refusal, snapshots,
resource reuse, independent review, budgets and cleanup. The final scanner
correction at ae252e15960d1439dda6331d8d1b535db79f415a passed 46 execution checks
plus model/core and documentation checks, with independent source review.

The DB-only readiness source classifier subsequently gained recognition of
createAgenticProcessStore, the typed adapter over the existing canonical store.
It remains a heuristic; operational checks are still required. Ordinary file
reads without a known canonical port remain flagged.

## Native observations

A real temporary Windows installation used PostgreSQL for governance and
Node 24/SQLite for the fixed reservation-service application. Model and reasoning
settings stayed fixed. Analysis and implementation reused one live thread;
independent machine review used a fresh read-only thread. The trusted broker
republished five declared product files byte-identically. The separate external
HTTP oracle passed20/20 and native/oracle process trees closed with zero active
processes. The owned PostgreSQL cluster was exported, stopped and removed.

The first native stop did not retain a filesystem errno/path and remains
INDETERMINATE. A separate in-memory reproduction proved a possible ENOENT race
in the old scanner. The reviewed fix tolerates only disappearing listed
children or explicitly optional roots, keeps other refusals, and retains bounded
diagnostics. The later native success did not observe that disappearance branch
and does not retroactively establish the first stop's cause.
