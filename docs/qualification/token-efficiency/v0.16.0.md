It used 62 model responses, 7,946,481 cumulative input tokens (including 7,560,704 cached tokens), 385,777 uncached input tokens and 35,867 output tokens over 2,181.267 seconds.

The historical compact003 result used 53 responses, 5,166,461 cumulative input tokens and 308,093 uncached input tokens; that historical native binary is unavailable, so those differences are descriptive observations only.
