# Experimental procedure profile: token-efficiency.v1

Status: opt-in research candidate; native adoption is not qualified.

The ordinary installer does not copy this directory into an installed skill.
It is packaged for an isolated qualification host that explicitly selects this
profile. Do not replace a user's skills, hooks, AGENTS block or accepted adoption
policy. Rollback selects the ordinary procedures and omits the experimental CLI
flags; retain all collected evidence.

Load `COMMON.md` once as a stable instruction prefix, followed by the relevant
procedure, then the current task and observed data. Keep common instructions
identical across matched trials. The task-specific files reference this common
prefix instead of repeating activation, authority, write and refusal rules.
This arrangement is a cache candidate, not evidence of a cache hit or token gain.

| Task | Procedure | Expansion authority |
| --- | --- | --- |
| Start or resume, including read-only work | `START.md` | Installed context-reload/start-session skills and WORKFLOW-KERNEL.md |
| Admitted product work | `WORK.md` | Installed task skill, admitted plan and native write controls |
| Receive a relay, close a cycle/session | `HANDOFF-CLOSE.md` | Installed handoff-admit, cycle-close and close-session procedures |

These procedures change scheduling of known consultations and deterministic
controls. They do not decide a cycle outcome, choose competing work, create an
accepted context policy, suppress a control or grant reusable write authority.
Missing complete mandatory context requires explicit expansion. Unknown skills
keep the full route. Keep the default startup/recovery route available.
